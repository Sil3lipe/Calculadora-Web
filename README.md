# Calculadora Web

Calculadora desenvolvida como um projeto pessoal/acadêmico para aplicar os conhecimentos adquiridos ao longo do semestre da faculdade em desenvolvimento web.

A aplicação permite realizar operações aritméticas por meio de uma interface com botões e um visor para exibir as expressões e os resultados.

## Funcionalidades

- Adição, subtração, multiplicação e divisão.
- Entrada de números decimais utilizando ponto (`.`).
- Cálculo de expressões pelo botão `=`.
- Limpeza do visor pelo botão `C`.
- Exibição da mensagem `Error` quando ocorre um erro ao avaliar uma expressão.

## Tecnologias utilizadas

- **HTML:** estrutura da interface e dos botões.
- **CSS:** cores, layout e estados visuais dos botões.
- **JavaScript:** atualização do visor e cálculo das expressões.

## Como executar

1. Baixe ou clone este repositório.
2. Mantenha os arquivos `index.html`, `styles.css` e `code.js` na mesma pasta.
3. Abra o arquivo `index.html` em um navegador.

Não é necessário instalar dependências ou iniciar um servidor.

Para utilizar a calculadora, clique nos números e operadores e depois no botão `=` para visualizar o resultado. Utilize `C` para limpar o visor e iniciar um novo cálculo.

## Estrutura do projeto

```text
nova_calculadora/
```

- Estruturação de páginas com HTML.
- Organização do layout com Flexbox e CSS Grid.
- Estilização de interações com `:hover` e `:active`.
- Acesso e atualização de elementos do DOM com JavaScript.
- Uso de funções e eventos de clique.
- Tratamento de exceções com `try...catch`.
